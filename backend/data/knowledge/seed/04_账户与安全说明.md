# 账户与安全说明

## 登录与账号信息

用户无法登录时，先确认使用的登录方式、账号标识、发生时间、错误提示和设备环境。密码错误、验证码错误、账号锁定、第三方登录失败、网络异常和登录态过期都可能导致登录失败。

用户忘记密码时，可通过已绑定的手机号或邮箱完成重置。客服不得要求用户发送原密码、短信验证码、完整 Token、完整 API Key 或其他可直接登录账户的敏感信息。

## 账户资料修改

修改邮箱、手机号、昵称或收货信息前，通常需要完成身份核验。用户应说明需要修改的字段和当前遇到的问题；涉及已绑定手机号不可用、实名信息变更或多个账户合并时，需要人工处理。

## 异常登录与安全保护

用户发现陌生登录记录、异常设备、非本人下单或可疑收货地址时，应优先建议修改密码、退出其他登录设备、检查绑定邮箱和手机号，并保留异常发生时间和订单信息。涉及疑似账户被盗、权限越权、资金风险或安全攻击时，应尽快转人工或安全支持处理。

## 两步验证与安全提醒

建议用户开启两步验证，并为账户设置长度不少于 8 位、包含字母和数字的独立密码。不要在公开渠道分享密码、验证码、银行卡信息、身份证照片或完整密钥。官方客服不会主动索取用户密码和验证码。

## 人工升级条件

账号被盗、异常登录持续发生、绑定信息无法核验、账户权限异常、非本人支付或用户明确要求人工处理时，应创建人工交接或交由安全支持继续核验。
